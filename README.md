# Zachary Pennington | Web Developer Portfolio

[View the portfolio](https://zacharyatom.github.io/Portfolio/)

This portfolio presents two projects from my web development coursework.

- **Horror Movie Explorer** uses JavaScript, TMDB, browser storage, and Google Maps to explore horror movies.
- **ZacharyAtom Gaming** is a six-page channel website with responsive navigation and a demo contact form. [Live site](https://zpennington-nwtc.github.io/final-project-portfolio/) · [Source](https://github.com/ZPennington-NWTC/final-project-portfolio)

Open `index.html` in a browser to preview the portfolio locally. The site uses HTML and CSS, and its images live in `public/projects/`. GitHub Pages serves the files directly from the repository.
